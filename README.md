# Aprender TypeScript: Guia Prático para Desenvolvedores JavaScript

## Sobre o projeto

Este projeto foi desenvolvido como parte da Atividade Extensionista II do curso de Análise e Desenvolvimento de Sistemas da UNINTER.

O objetivo é apresentar, de forma simples e prática, os principais conceitos do TypeScript para pessoas que já possuem algum contato com JavaScript.

O conteúdo foi desenvolvido em formato de vídeo educativo, utilizando exemplos práticos no Visual Studio Code para demonstrar como o TypeScript pode ajudar na identificação de erros e na organização do código.

## Conteúdos abordados

O vídeo apresenta exemplos de:

- Tipos básicos (`string`, `number` e `boolean`);
- Inferência de tipos;
- Arrays;
- Objetos;
- Interfaces;
- Union Types;
- Funções com parâmetros e retorno tipados;
- Identificação de erros pelo TypeScript;
- Compilação de TypeScript para JavaScript utilizando `tsc`.

## Tecnologias utilizadas

- TypeScript
- JavaScript
- Visual Studio Code
- Node.js
- Git e GitHub

## Exemplos

Os exemplos utilizados no vídeo estão disponíveis neste repositório e podem ser executados para acompanhar as demonstrações apresentadas.

A aplicação teve como objetivo verificar se uma abordagem simples e prática poderia auxiliar os participantes na compreensão dos conceitos introdutórios de TypeScript.
